FAST HUBSHOP — DEMO STOREFRONT

HOW TO OPEN
1. Open index.html in a modern browser (Chrome recommended).
2. On a phone, download/extract the ZIP first, then open index.html using a browser or use a computer.
3. This is a front-end demo, not a production-ready store.

WORKING DEMO FEATURES
- Responsive storefront, search, category filters and sorting
- Sample products and discounts
- Cart quantity controls
- Demo checkout form and payment-method selection
- Demo order history
- Local-only owner settings and add-product form
- Contact form interaction and privacy notice

IMPORTANT SECURITY LIMITATIONS
- No real payments are processed.
- UPI, wallet, online payments and COD are labels/demo interactions only.
- No secure customer accounts, backend, shared database, admin authentication, stock management, image upload server or real order fulfillment.
- Demo data is stored in the browser's localStorage and is not secure or synced to other devices.
- Do not enter real customer data or payment credentials.
- Before launch, connect a secure backend/database, HTTPS hosting, admin login with MFA, role-based access, validated server-side orders, inventory management, privacy/terms/returns/shipping policies, and a reputable payment gateway. Never collect or store UPI PINs/card details yourself.
